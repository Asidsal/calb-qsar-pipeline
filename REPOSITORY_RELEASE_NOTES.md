# Computational research repository contents

This distribution includes curated data, QSAR source workflows, generation and docking records, independent CAL-028/CAL-015 50 ns MD analyses, full-run MM/GBSA summary tables, and the proposed CAL-028 convergent synthesis scheme.

The main manuscript and Supporting Information are maintained outside this repository and are deliberately excluded. Full-atom production trajectories and raw per-frame MM/GBSA logs are archived separately due to size.

The computational methodology and numerical results are described in the code, source notebooks, and accompanying result tables.
