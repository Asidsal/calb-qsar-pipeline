# CYP51 pocket visualizations

These molecular figures, overlays and interactive HTML snapshots were generated using *specific exported coordinate frames* from the 50 ns trajectories and are stored here without alteration. The `.html` viewers show three static MD states (first, representative, final), **not continuous 50 ns playback**. The video-rendering source notebook is at `../workflows/cartoon_fast_resumable_colab.ipynb`. Actual 50 ns trajectory video files are **not** included in this repository.

The 3D coordinate snapshots with residues and atoms are in `../analysis_50ns/advanced/CAL028/` and `../analysis_50ns/advanced/CAL015/`. A separate folder contains manuscript-ready 2D panels/plots, not new 2D chemistry interaction diagrams.
